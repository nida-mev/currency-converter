# Currency Converter

## Project Overview
A beginner-level web development project that demonstrates a currency converter interface using HTML, CSS, and JavaScript.

## Technologies Used
- HTML for page structure
- CSS for styling
- JavaScript for interactive functionality

## Learning Goals
- Practice JavaScript fundamentals
- Understand DOM manipulation
- Learn how front-end components work together

## Credits
This project was developed as a learning exercise based on the CurrencyConverter example from Shradha Khapra's JavaScriptSeries.

Source: https://github.com/shradha-khapra/JavaScriptSeries/tree/main/CurrencyConverter
